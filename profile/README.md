## 🚀 Who We Are

> **Vienify** is a software studio focused on building delightful products for the creator economy.
> We believe every story deserves a beautiful voice — so we build the tools that give it one.

- 🎯 **Mission** — empower audio storytellers to produce more, faster, and better.
- 🧠 **Focus** — AI text-to-speech, content production pipelines, creator analytics.
- 🛠 **How we ship** — small team, sharp tools, obsessive attention to UX.
